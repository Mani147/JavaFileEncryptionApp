# Java File Encryption App

## Description
JavaFileEncryptionApp is a simple application built in Java for file encryption and decryption. It uses advanced cryptographic algorithms to ensure secure file storage and transmission. The application is built with an intuitive interface and allows users to encrypt and decrypt files using a passphrase.

## Features
- **Encrypt Files**: Secure your files using encryption algorithms.
- **Decrypt Files**: Restore original files by decrypting them using the correct passphrase.
- **Supports Multiple File Formats**: Encrypt any file format (text, images, etc.).
- **Secure**: Uses AES (Advanced Encryption Standard) for strong encryption.

## Technologies Used
- **Java**: The core language for development.
- **JavaFX**: For the graphical user interface (GUI).
- **AES Algorithm**: For file encryption and decryption.
- **SQLite**: To store file records such as filename, path, and timestamp.

## Installation
1. Clone the repository:
    ```bash
    git clone https://github.com/YourUsername/JavaFileEncryptionApp.git
    ```

2. Navigate to the project directory:
    ```bash
    cd JavaFileEncryptionApp
    ```

3. Compile and run the application using your preferred IDE (e.g., IntelliJ IDEA, Eclipse) or use the command line:
    ```bash
    javac Main.java
    java Main
    ```

4. Make sure to have the necessary libraries for JavaFX and SQLite integrated into the project.

## Usage
1. Launch the application.
2. Select the file you want to encrypt or decrypt.
3. Enter the passphrase to encrypt or decrypt the file.
4. Save the resulting file in the desired location.
